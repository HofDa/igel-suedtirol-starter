# Claude Code Hinweise

Lies zuerst `AGENTS.md`; dessen Regeln sind verbindlich.

Arbeite in kleinen Schritten. Prüfe vor jeder Änderung insbesondere:

- i18n-Vollständigkeit
- Schutz exakter Standorte
- Trennung personenbezogener Daten
- Server-/Client-Grenzen
- Offline-Verhalten

Nutze `npm run check` und `npm run build`, bevor ein Arbeitspaket als abgeschlossen gilt.
